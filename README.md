# Journey of Us

A personal timeline web page celebrating our relationship milestones.

## About

A single-page HTML site that displays our journey together — from the first meeting to the latest milestones — along with a day counter and a hidden love letter surprise.

## Features

- Timeline of relationship milestones
- Live day counter since we first met
- Hidden love letter revealed on button click
- Confetti animation

## Running Locally

Just open `index.html` in a browser — no build step or dependencies required.
